# Code and derived data: *A Controlled Comparison of Factorised and Monolithic Models for Correcting Predicted Regions in Glioma Segmentation After Treatment*

This package accompanies the revised manuscript (Discover Computer Vision). It contains everything needed to
reproduce each table and figure from the saved intermediate files, and the code needed to regenerate those
intermediates from the public MU-Glioma-Post data.

## What is (and is not) included

| Folder | Content |
|---|---|
| `scripts/original_pipeline/` | Fold construction, nnU-Net trainer override (patient-grouped folds), region extraction with oracle labels, corrector training and the original (first-version) analyses. |
| `scripts/revision_analysis/` | Revision code: extraction with sliding-window or tiled inference, protocols P0/P1/P2, matched coverage, calibration/RC analyses, protocol audit, ceiling decomposition, Dice/HD95, reserved-cohort evaluation. |
| `scripts/figures/` | Figure scripts and the shared style module. |
| `protocol/` | `REVISION_PROTOCOL_LOCK.md`, written before any corrected-protocol result or reserved-cohort result was computed (with two dated amendments), and the static numbers file. |
| `splits/` | Patient-level assignments: development/reserved split, the five base-network folds, the nnU-Net train/validation splits, and the P2 inner-fold assignment. Patient identifiers are the dataset's own anonymised identifiers. |
| `derived/region_tables/` | One row per candidate region: patient, case, base network, source class, size, ground-truth voxel counts per class, mean class probabilities, pooled decoder-feature means and standard deviations. Development and reserved cohorts; sliding-window (primary) and tiled (as-submitted) extractions. |
| `derived/predictions/` | Out-of-fold class probabilities of every corrector, protocol and seed. |
| `derived/results/` | JSON/CSV result files behind every table and figure (prefix `slide_` = primary pipeline, `tiled_` = as-submitted pipeline), including per-case Dice and HD95. |

Not included: the MU-Glioma-Post images and labels (download from TCIA, <https://doi.org/10.7937/7K9K-3C83>), the five
trained nnU-Net checkpoints (about 0.8 GB each) and the per-case prediction masks. The scripts regenerate masks and
region tables from the checkpoints; retraining the base networks takes about 17.5 GPU-hours (one RTX 5060 Ti).

## Environment

Python 3.13.9; torch 2.11.0+cu128; nnunetv2 2.8.1; dynamic-network-architectures 0.4.4; acvl-utils 0.2.6; numpy 2.3.5;
scipy 1.16.3; pandas 2.3.3; scikit-learn 1.7.2; matplotlib 3.10.6; pyarrow 21.0.0. Windows 11. On Windows with several
OpenMP runtimes, set `KMP_DUPLICATE_LIB_OK=TRUE`.

## Quick reproduction from the saved outputs (no GPU, no images, a few seconds)

```
python scripts/reproduce_from_saved_outputs.py
```

This stages the result files of `derived/results/`, loads the saved analysis outputs and prints the headline numbers of the
study (development and reserved cohorts, primary protocol P2) directly from them, then exits with code 0. Requires Python 3 with
`numpy` and `pandas` (no `torch`). The manuscript text is not distributed with this release; the entrypoint therefore checks the
result files and their headline values, not the text of the paper. It does *not* retrain the networks or re-run inference; that is the
"full retraining" route below, which needs the MU-Glioma-Post images, the five trained checkpoints (or about 17.5 GPU-hours to
retrain them) and an nnU-Net v2.8.1 installation. Figures are regenerated by the scripts in `scripts/figures/` from the same result files.

## Configuring paths

No script contains a machine-specific path. Paths are resolved by `scripts/mriseg_paths.py`: `MRISEG_ROOT` is the project tree
holding `data/`, `nnUNet_data/` and `split_v2/` (needed only to retrain or re-extract; the patient assignment and fold files
are also released in `splits/`), `MRISEG_WORK` is where outputs go, and `PYTHON` selects the interpreter used by the `.ps1`/`.sh`
launchers.

## Reproduction from raw data (full retraining)

1. Download MU-Glioma-Post, convert to the nnU-Net raw layout (`Dataset001_MUGliomaPost`) and run nnU-Net planning and preprocessing with the `nnUNetResEncUNetMPlans` plans.
2. Train the five base networks with the trainer in `scripts/original_pipeline/nnUNetTrainerPTDROOF.py` (reads `splits/NNUNET_TRAIN_VAL_SPLITS_DERIVED.json`).
3. Extract regions and masks: `python extract_regions_and_masks.py --set dev --fold F --infer sliding` for F = 0..4 (and `--set heldout` for the reserved cohort, **run only after steps 4-6 are final**; `--infer tiled` reproduces the first version).
4. `REV_VARIANT=slide python a2_run_protocols.py` (trains typed and monolithic correctors under P0/P1/P2).
5. `a3_compare_models.py`, `a1_protocol_audit.py`, `a4_calibration_rc.py`, `a5_ceiling_decomposition.py`, `a6_dice_hd95.py --set dev`, `a7_dice_summary_dev.py`, `a8_extra.py`.
6. `h3_heldout_eval.py` (the one-shot reserved-cohort evaluation).
7. The figure scripts in `scripts/figures/` regenerate the figures from the result files.

Author-side helper scripts (manuscript and response preparation, submission packaging, building this release) are not part of the release.

## Cohort reconciliation

The TCIA release (version 1) has 203 patients and 596 time-point folders, 594 with a label file. This study analyses 579 of them: 439
development time points (two development time points, PatientID_0187 Timepoint_3 and PatientID_0191 Timepoint_1, have no label file) and
140 reserved time points. The reserved patients have 155 labelled time points; 15 of them were never converted to nnU-Net input because the conversion script excluded
the cases of a superseded case-level test list. They are listed, with the counts, in `COHORT_RECONCILIATION.json`.

`REV_VARIANT=slide` (default) selects the primary sliding-window pipeline; `REV_VARIANT=tiled` selects the as-submitted pipeline.

## Notes for readers

* The first version of this study used non-overlapping tiled inference and a cross-fitting protocol (P0) in which correctors were tested on decoder features of a different base network from the one that produced their training features. Both are documented and retained (`tiled_*` results, Supplementary Tables S3 and S6, Figures S2-S12); the revised main text uses sliding-window inference and the nested per-network protocol P2.
* Results of the original protocol are reproducible: running `a3_compare_models.py` with `REV_VARIANT=tiled` reproduces the first version's typed/monolithic means (-0.0384 / -0.3299) exactly.
* Bootstrap resamples patients only (2,000 resamples, seed 20261002); no p-values are computed.
